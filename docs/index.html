04. Analysis notes & guardrails

What this model can, and cannot, establish

01 / Source
Historical observational data

Counts and review comparisons are inherited from the source Olist pipeline and its SQL aggregate exports. No raw Olist files are bundled with this portfolio.

02 / Statistical handling
Sample-size-aware prioritization

State risk uses a 200-order prior centered on the full national late rate. Wilson intervals describe binomial sampling uncertainty; neither is a causal confidence interval.

Adjusted p = (late + 200 × national_p) / (n + 200)

03 / Decision logic
Constrained pilot, not a forecast

Ranks by expected risk per unit cost (uniform costs), applies a state-level capacity cap and budget. Benefits use explicit hypothetical values; only an A/B or randomized operational trial can estimate actual impact.

Avoided = treated × adjusted_p × assumed_RRR
