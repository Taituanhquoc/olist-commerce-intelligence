# Olist Commerce Intelligence — Delivery Promise Lab

This repository is the portfolio project of Nguyễn Quốc Anh, extending the public Olist e-commerce analytics project with a delivery-risk prioritization and business decision simulation. The complete, attributed project is being imported from the uploaded project bundle.

**Data origin:** Olist public e-commerce dataset. **Upstream attribution:** [TobyTY/ecommerce-analytics-olist](https://github.com/TobyTY/ecommerce-analytics-olist).

Business impact and scenario assumptions are illustrative, not measured operational gains. See the full README, NOTICE and documentation once the bundle is extracted.
